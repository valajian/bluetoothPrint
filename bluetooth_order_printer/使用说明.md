# 蓝牙点单打印 APP（精臣B3）

## 📱 编译完成

**APK 文件位置**: `bluetooth_order_printer\蓝牙点单.apk` (约 85MB)

---

## 使用方法

### 1. 安装 APK
将 `蓝牙点单.apk` 传输到安卓手机，打开安装即可。

### 2. 手机系统蓝牙配对（重要！）
在 **手机系统设置 → 蓝牙** 中，先与精臣B3打印机配对：
1. 打开精臣B3打印机电源
2. 手机进入 设置 → 蓝牙 → 配对新设备
3. 找到设备名类似 `B3_xxxx` 的设备并完成配对
4. **配对成功后** 再打开本 APP

### 3. APP 使用流程
```
第一步：点击底部「蓝牙」标签 → 点击"扫描已配对设备" → 找到 B3 设备点击"连接"
第二步：点击底部「新建订单」标签 → 填写桌号、人数、添加菜品
第三步：点击「保存并打印小票」→ 打印机自动出纸
第四步：点击底部「历史」标签 → 可重新打印历史订单
```

## 常见问题排查

| 问题 | 解决方法 |
|------|----------|
| 扫描不到设备 | 先去手机系统蓝牙设置配对；确保打印机已开机 |
| 连接失败 | 检查打印机蓝牙是否已配对；重启打印机再试 |
| 打印乱码 | 正常（GBK编码已处理）；如果仍乱码，检查打印机固件版本 |
| 权限弹窗 | 允许所有蓝牙和定位权限请求 |
| 打印机无反应 | 点击断开→重连；确认纸张已装好 |

---

## 技术说明

- **蓝牙类型**: 经典蓝牙 SPP（非 BLE）
- **打印协议**: TSPL 指令集，50mm 连续热敏纸
- **中文编码**: GBK（兼容 GB2312）
- **依赖包**: shared_preferences（本地存储）
- **Android SDK**: compileSdk 35，minSdk 21
